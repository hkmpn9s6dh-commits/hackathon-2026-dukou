## 4. 动机可懂度（评委会问的那一条）

评委（GLM-5.3F）在盲排里明确指出：「五音动机到底成不成旋律——谱上只能确认那几条能量线在，
听不出它们站不站得住。」

这一条可以量。每个动机音的起音后 60 ms–600 ms 里，量它基频处的能量相对
**两侧各 1/3 八度**（含垫子的谐波，也就是它要冒出来的那片背景）的中位数高多少：

| 判据 | 结果 |
|---|---|
| 中位谱突出度 ≥ 6 dB | **+23.7 dB** |
| 80% 以上的音 ≥ 3 dB | **100%**（29 个音全部 ≥ 3 dB，最低 +12.9 dB） |

原始数据在 `proof/motif.json`。

**怎么读这个数字**：动机在混音里不是"垫子的一部分"，它是一条明确突出的线。
但 +23.7 dB 也偏高——说明它坐在垫子的一个频谱空档里（垫子在 500–1200 Hz 本来就薄），
是"一条线悬在上面"，不是"一条线融在里面"。这是设计使然（Cinematic 里独奏乐器就是要浮出来），
也可能是这首曲子最该被耳朵复核的地方。

## 6. 我确实不知道的事（不许当成"应该没问题"）

写这份东西的 agent **没有耳朵**，也没听过这首曲子的任何一个音。以下是它**无法**判断、
必须由人或真正的评委来判断的：

1. **好不好听。** 所有指标都只证明"结构对、平衡对、动态对、不糊"，证明不了"动人"。
2. **音色是否可信。** 钢板派生的箫会不会听起来像合成器、弦垫会不会像风琴，
   这类"像不像"的判断只能靠耳朵。程序能证明的是"它确实是那块板的谐波"。
3. **和声在听觉上是否成立。** D 多利亚 + 借 ♭VI 在纸上是对的（`tests` 里锁了撞音），
   但"这个转折打不打动人"是另一回事。
4. **+24.6 dB 的动机突出度是不是过头了。** 这个数字证明它听得见，不能证明它刚刚好。
5. **整体的"电影感"。** 频谱、动态、段落都对，但电影感是文化性的，不是指标性的。

这三条已经写进交件说明（`docs/05-SUBMISSION.md` §0）：**用户要听一遍再提交。**
