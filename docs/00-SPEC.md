## 0. 官方评分表（原文照抄）

来源：`nextsoundawards.com/awards` 与 `/competition-rules`（2026-11-16 核）。

> **PROFESSIONAL JURY · 80%** — The jury judges singles as finished songs and LPs as complete

> **VALIDATED AUDIENCE · 20%** — Eligible listener ratings… the adjusted audience score for each

关键事实：

| 项 | 值 |

| 窗口 | 2026-10-01 00:00 UTC → **2026-12-01 23:59 UTC**（北京 12-02 07:59） |
| 类目 | Pop / Electronic / **Cinematic** / Experimental，一件作品只能选一个 |

受众分只有 20%，而且用贝叶斯收缩把权重压到 20 个先验评分上——**这不是点赞比赛**。
所以这件作品要赢的唯一路径是 J（评委分）。

## 1. 演示脚本：听众要经历什么

一个渡口，天亮前后，摆四次渡。

| 段 | 时间 | 听众该听到的 | 对应的曲式事件 |
|---|---|---|---|
| I 未亮 | 0:00–1:00 | 只有水和一台柴油机。有一个东西在低处隐约重复，但听不出是旋律 | 动机被低通压到 700 Hz、力度 0.16，"埋着" |
| II 微亮 | 1:00–2:00 | 那个东西第一次完整地唱出来；远处有浮标的钟 | 动机首次完整（D 多利亚），第二次下五度像回声 |
| III 日出 | 2:00–3:00 | 全奏，船体的闷响变成心跳；动机上行到 G 多利亚 | 转调 +5，每拍一次闷响，三下大锣 |
| IV 对岸 | 3:00–4:00 | 只剩回声，动机碎成单音，最后一音是 9 音，不解决 | 借 ♭VI（B♭maj7），旋律落在 E |

最后 12 秒是余响：引擎熄了，江还在。

## 2. 核心约束（这一版真正的原创点）

**单源作曲。** 全曲所有声音由同一个 400 ms 的模态合成脉冲派生：

| 声音 | 怎么从钢板来 |
|---|---|
| 钟 / 锣 | 同一块板换基频再敲一次（模态比例不变，板越小响越短） |
| 水 | 板的噪声尾颗粒化；另有一层极缓慢起伏的带状噪声 |
| 引擎 | 板低通到 140 Hz，循环成一个 3.3 s 冲程，再按 7.6 Hz 点火调幅 |
| 弦垫 | 板的模态谱被"冻结"成谐波列（频域放分音 + 三份微失谐） |
| 箫 | 对第 k 次谐波，去板谱里找离 k·f 最近的模态取幅度 |
| 房间 | 板自己的尾巴拉伸 + 谱相位随机化 + 拉平倾斜，就是混响 IR |

这条约束是**机器可验证**的：渲染时每条声部记一笔来源，验收断言"来源集合只有一个元素"。
（2026-11-16 实测：209 次声部调用，来源集合 = `{steel_impulse@seed20261201}`。）

它服务的正是评委七项里的 "how the AI-assisted process serves the music"：
不是"用 AI 生成一段音乐"，是**让一个 AI 写出一套只从一个声源长出整首曲子的合成谱**，
而约束本身听得见——全曲音色同源，像同一个空间里的事。

## 3. 可判定的验收条件（写在实现之前）

| # | 条件 | 判据 |
|---|---|---|
| AC-1 | 时长 | 252.0 ± 0.05 s |
| AC-2 | 集成响度 | −14.0 ± 0.5 LUFS |
| AC-3 | 真峰值 | ≤ −1.0 dBTP（WAV）；MP3 解码后 ≤ −0.8 dBTP |
| AC-4 | 动态 | LRA 6–16 LU |
| AC-5 | 不削波 | 无样本 \|x\| ≥ 1.0 |
| AC-6 | 无直流 | \|offset\| < 1e-3 |
| AC-7 | 单声道兼容 | 折叠后额外损失 < 3 dB |
| AC-8 | 立体声 | 相关 0.05–0.85 |
| AC-9 | 频率平衡 | 八度带相对 1 kHz 与目标曲线最大偏差 ≤ 4 dB |
| AC-10 | 结构 | III 段最响；II > I + 2 dB；IV < II − 4 dB |
| AC-11 | 结尾 | 末 5 s 比 30 s 前那一窗低 3 dB 以上 |
| AC-12 | 单源 | 声部来源集合 = {steel_impulse@seed20261201}，调用数 > 40 |
| AC-13 | MP3 | 有 ID3v2、≥192 kbps、解码后响度与 WAV 差 ≤ 0.5 LU |
| AC-14 | 计量可信 | 自建响度表与 `ffmpeg ebur128` 差 ≤ 0.2 LU；真峰值差 ≤ 0.5 dB |
| AC-15 | 确定性 | 两次渲染 sha256 一致 |
| AC-16 | 乐理 | 旋律不含 ♭7；低音区（< MIDI 55）无相邻半音；终止不落主音 |

AC-12、AC-16 是这首曲子特有的：前者锁住"单源"这个概念，后者锁住"这首曲子不许犯的错"。
其余是任何要交出去的音频都该过的。

## 4. 不做什么

- 不做人声、不做歌词（本机没有歌声合成；Cinematic 类目不要求）
- 不用任何采样库、不用任何生成式音频模型
- 不为了响度把动态压死（LRA < 6 直接判失败）
- 不在过闸 D 之前做封面与视频（照《清台作战》规则 2）
- 不投稿、不注册账号（对外动作留给用户）
