# 尺子：这场比赛的"往届得奖作"不存在，那用什么当尺子

闸 D 的规矩是：成品和**往届得奖作至少 5 件**混在一起盲排，排在至少 3 件之上才算过。
这一场做不到，原因写在下面，然后是替代方案。

## 1. 为什么没有往届作品

NEXT SOUND Awards 是 **2026 年首届**。官方页面写的是 "2026 PRIZE POOL"、
"2026 edition"、"Winners will be announced by 31 March 2027"——第一年，没有往届得奖名单。

这和赛道 M（数字武当杯，首届）是同一类情况。

## 2. 能不能拿到外部同类作品当尺子

**不能。** 2026-11-16 实测本机网络：

| 源 | 结果 |
|---|---|
| `incompetech.com`（Kevin MacLeod CC-BY 曲库） | 页面 200，但曲目列表是 JS 动态加载，直链拿不到 |
| `archive.org`（高级检索 API） | **000**，不通 |
| `commons.wikimedia.org` / `en.wikipedia.org` / `upload.wikimedia.org` | **000**，不通 |
| `api.openverse.org`（CC 音频聚合） | **000**，不通 |
| `musopen.org` / `cdn.pixabay.com` | 403 |
| `freesound.org` | 200，但下载要 API key，本机没有 |

也就是说：**这台机器下载不到任何一首外部音乐**。没有参考音频，就画不出它们的聆听表，
混不进同一个盲排队列。

## 3. 替代方案（这一场实际怎么过的闸 D）

三段，缺一不可：

### A. 三个读法的盲排

同一份乐谱，三个**配器/电平取舍不同**的读法（甲/乙/丙，随机字母，评委不知道哪个是哪个）：

| 代号 | 读法 | 差别 |
|---|---|---|
| 甲 | 水线 | 只有水、弦垫、箫、钟；没有引擎、没有闷响、没有大锣 |
| 乙 | 船 | 全编制 |
| 丙 | 钟 | 钟与锣为主，引擎与闷响压低，弦垫退后 |

这不是"三版微调"——是三种对同一份谱子的读法。挑一个交出去，是一个真的艺术选择。

判据：**定稿那个被排第 1**，且两位评委一致。

### B. 官方七项的直接打分

评委按 NEXT SOUND 原文的七项（musical quality / originality / artistic direction /
emotional impact / coherence / production / creative use of AI）各 0–10，
只读文档证据（SPEC、乐谱、声学报告、聆听表），**不给我的自评**。

判据：平均 J ≥ 7.0，且 production 与 emotional impact 都不低于 6。
理由：受众分只占 20%，J 就是一切；J 到不了 7 就进不了终评的档次。

### C. 客观制作审计

八度带平衡、动态范围、单声道兼容、真峰值、与 ffmpeg 独立实现的交叉核对——
这些不参与"过不过线"，但它们是评委 B 段打分的证据基础，也是唯一不靠判断的部分。

## 4. 这套替代方案的弱点（写清楚，不藏）

1. **评委听不到。** 他们读的是频谱图、波形和响度曲线。这套东西能看出
   "结构清不清楚、低频糊不糊、动态有没有起落"，看不出
   "这个和弦好不好听、这个音色动不动人"。
2. **没有外部锚点。** 三个读法是我自己的三版，没有一个"外面的专业作品"压阵。
   所以 B 段的绝对分（≥7.0）承担了原本由外部尺子承担的那部分。
3. **同一双手做的。** 三个读法、混音、聆听表都出自同一条流水线。
   评委是外人，但作品与证据是同源的。

所以这一场的闸 D 只能算**条件性通过**——和赛道 M（武当，首届）同样的口径：
过线的意义是"在现有条件下尽力了，把判断交给用户与真正的评委"。
