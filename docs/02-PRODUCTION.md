# 制作记录：这套混音是怎么定下来的

> 这份文件只记**做法与数字**，不记"听起来怎么样"——写它的 agent 听不见，
> 凡是"好听/不好听"的判断都留给评委与用户。

## 1. 九条总线与它们的电平

做法：每一条总线先按自己的内容量出集成响度（BS.1770-4，K 加权），
再按目标表拉平。**用响度而不是 RMS 对齐**，是因为低频总线的 RMS 很大但听起来不响，
用 RMS 会把它推成泥。

| 总线 | 目标 LUFS | 备注 |
|---|---|---|
| pad 弦垫 | −20.0 | 铺底，占大部分时间 |
| bass 低音线 | −36.0 | 和弦根音低八度，只用 240 Hz 以下 |
| reed 箫 | −22.0 | 动机的载体 |
| bell 浮标钟 | −27.0 | 稀疏，靠响度门自动只量它出现的时刻 |
| gong 大锣 | −33.0 | 三下，加第四段一下很轻的 |
| water 水 | −25.0 | 全程 |
| engine 引擎 | −33.0 | 7.6 Hz 点火 |
| knock 船体闷响 | −37.0 | 全曲的拍点 |
| air 空气层 | −34.0 | 只做空间 |

初版这几条全是 RMS 对齐，结果 93% 的能量落在 120 Hz 以下、谱重心 106 Hz——一锅泥。
换成响度对齐之后掉到 66%，还要再修（见第 3 节）。

## 2. 混响：用那块板自己的尾巴当房间

```
拉伸 → 谱相位在 300 Hz 以上随机化（低频保留原相位，保单声道兼容）
     → 按 −0.45 的幂律拉平倾斜（200 Hz 起） + 5.2 kHz 之后的空气吸收
     → 双段指数衰减 → 按能量归一
```

两个坑，都是量出来的：

1. **按峰值归一 IR 会把整首歌泡进低频。** 峰值归一意味着卷积的增益是
   `sqrt(Σ ir²)`，而这条 IR 的能量几乎全在低频。初版湿声比干声高 12.5 dB，
   于是全曲低频占比 68%、动态范围 LRA 只剩 1.1 LU（等于一条砖）。
   **判据：湿声与干声的 LUFS 差应 < 3 dB。**
2. **完全不相关的左右 IR 会让单声道折叠掉 3 dB 以上。** 修法：300 Hz 以下左右共用相位，
   把混响的低频并回单声道。

## 3. 频谱匹配：把倾斜拉平，再用目标曲线收口

母带里做两遍匹配：量八度带 → 与目标曲线比 → 取修正量（限幅 ±8 dB）→ 平滑插值到场强 →
**倒谱法转最小相位 FIR**（没有预振铃）→ 卷积。

两遍是必须的：第一遍拉完会过冲（16 kHz 一度高出目标 10.8 dB），第二遍收掉。

| 八度带 | 31.5 | 63 | 125 | 250 | 500 | 1k | 2k | 4k | 8k | 16k |
|---|---|---|---|---|---|---|---|---|---|---|
| 实测（相对 1 kHz） | −7.1 | −1.6 | −1.4 | +1.8 | +1.1 | 0 | −2.0 | −4.7 | −9.4 | −18.1 |
| 目标 | −7.0 | −3.0 | −0.5 | +1.0 | +1.5 | 0 | −1.5 | −4.5 | −9.0 | −16.0 |
| 偏差 | −0.1 | +1.4 | −0.9 | +0.8 | −0.4 | 0 | −0.5 | −0.2 | −0.4 | −2.1 |

最大偏差 **2.1 dB**。

## 4. 立体声：三个做法

- 弦垫**按音分声像**（五个音五个位置），不是整块垫子摆一个位置——和弦被摊开，
  而且每个音本身还是单声道源，折叠不吃亏。
- 箫、钟在**对侧加 2.5–4 ms 延迟**（Haas），把声像做实。
- 低频（引擎、闷响、低音线）**全部居中**。

结果：相关 0.165、单声道折叠额外损失 2.88 dB（门槛 3 dB）。

## 5. 段落包络与总线 EQ

- 段落增益：0.28 / 0.55 / 0.85 / 0.55 / 0.30，用 6 秒窗平滑，避免段落交界"台阶"。
- 总线 EQ：30 Hz 高通、300 Hz −2 dB（去箱音）、2.4 kHz +1.2 dB（箫的芯）、8.5 kHz 高架 +1.6 dB。
- 母带：去直流 → 两遍频谱匹配 → tanh 软削波（drive 0.55，只在峰值附近）→ 对响度 → 限幅（前瞻 8 ms、释放 160 ms、4 倍过采样真峰）。

**留 0.2 dB 余量**：母带定 −1.2 dBTP，因为 MP3 编解码会让真峰上冲 0.1–0.2 dB。
第一次定 −1.0，MP3 解回来是 −0.80，正好压在门槛上，不过。

## 6. 踩过的坑（都是量出来的，不是猜的）

| 现象 | 根因 | 判据/修法 |
|---|---|---|
| 全曲 LUFS +28、LRA 1.1 | IR 按峰值归一，湿声比干声高 12.5 dB | 湿/干 LUFS 差 < 3 dB |
| 谱重心 106 Hz、93% 能量在 120 Hz 以下 | 总线按 RMS 对齐 + 那个低频 IR | 改响度对齐 + 拉平 IR 倾斜 |
| 单声道折叠掉 3.16 dB | 左右 IR 完全不相关、水左右用两个独立种子 | 低频共用相位；水改成同源两声道 |
| 「16 kHz 高出目标 10.8 dB」 | 匹配只做一遍，过冲 | 两遍匹配 |
| 读回来的 WAV 峰值 228 | 24-bit 是二补数，最高位为 1 时没补符号位 → −0.5 读成 +1.5 | 补 `i32[:,3]`；另写 `wavio.py` 替掉标准库 `wave`（它读 24-bit 会少读 6 字节） |
| 时长 251.99998 s | `52 × (4×60/52) + 12` 的浮点尾巴 | `round(..., 6)` |
| 弦垫听不出和弦音（110 Hz 只有峰值的 1%） | 用「梳状 EQ 提亮一片噪声云」的做法，低频压不动 | 改成频域直接放谐波列（板谱冻结成谐波），再用 IFFT |
| 钟在高音区短到听不见 | 用重采样移调，音高与时长被绑死 | 改成「同一块板换 `base_hz` 再敲」，衰减按 `(82.4/f)^0.30` 缩放 |
| 力度加大反而更暗 | 模态幅度指数写反（低阶衰减得比高阶多） | `a = amp·(0.08+0.92·s)^(1+0.09·ratio)`，指数随阶数增大 |
| 引擎听起来是嗡嗡声 | 用 welch 量 7.6 Hz 调幅时 `nperseg=8192`，频率分辨率 5.86 Hz，分不清 7.6 与 5.86 | `nperseg=65536`，并改用低通取包络 |
